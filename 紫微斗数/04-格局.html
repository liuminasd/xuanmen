格 局

星曜组合见格局 · 命宫强弱定高低

格局总纲

星曜组合的质变——独星为材，合局为器

格局是紫微斗数中星曜组合产生的质变。一颗主星代表一种材质，而多星聚合、四化会照则如同将材料锻造成器——格局即是那把成型的刀剑。识格局者，观盘如观画；不识格局者，只见星星点点。 ——《紫微斗数全书》

一、命宫强弱五等

先定命宫根基，再论格局层次

论格局之前，必先审视命宫强弱。命宫为一生之根基，如同地基决定建筑高度。紫微斗数将命宫分为五等：

等级名称核心条件人生走向
★★★★★ 强格 主星庙旺坐命 + 左辅/右弼/文昌/文曲/天魁/天钺拱照 + 三方四正吉化（化禄/化权/化科会照） 先天根基深厚，人生顺遂，遇难有贵人扶持，成就较高，为上等命格
★★★☆☆ 平格 主星得地（非庙旺亦非落陷）+ 一般辅星配置 + 无大煞冲破 中等人生，有起有伏。需后天努力补先天之不足，吉凶参半
★★☆☆☆ 弱格 主星落陷坐命 + 擎羊/陀罗/火星/铃星/地空/地劫会照 + 化忌冲破 人生波折较多，事倍功半。但若后天修德积善，亦可转祸为福
★☆☆☆☆ 空宫 命宫无主星，需借对宫（迁移宫）星曜为用。空宫非凶，但根基不稳 随环境影响极大——近朱者赤，近墨者黑。借得吉星则吉，借得凶星则凶
★★★★★ 特殊格 特定星曜组合形成格局（如下列十大格局）。无论命宫强弱，格局自成一体 格局之力可越命宫等级——弱宫遇好格局如枯木逢春，强宫遇凶格局似锦上添乱
⚠ 重要提醒：命宫强弱只是先天底色，绝非命运判决书。许多人命宫平平却成就斐然——因为大限流转可改先天。弱格行强运，胜过强格行衰运。
记忆要诀：强平弱空特，五等如阶梯。强格根基厚，空宫随风移。特殊格局出，等级可跃级。

二、十大特殊格局速查

精中选精 · 核心格局一览

以下十大格局为紫微斗数中最具代表性的特殊格局，涵盖富贵、才华、权势、财运各维度。每格详列组成、条件、含义及现代解读。

格一 · 三奇嘉会 大吉·才华
组成：化禄 + 化权 + 化科 三者同宫或三方四正会照
条件：三奇不必同宫，三方（命·财·官）互照亦成立。若三奇+禄存/天马更增贵气。最忌地空/地劫冲破。
含义：才华横溢，名利兼收。"禄"为财富机遇，"权"为掌控执行力，"科"为名声学识——三者齐聚，人生如虎添翼。
现代解读：三奇嘉会之人往往能在专业领域崭露头角。若三奇在命宫→自身能力突出；在财帛→经商致富；在官禄→仕途/职场顺遂。
层次区分：三奇同宫 > 三奇三合会照 > 两奇+一奇在大限补足。
典型人物意象：跨界多面手——既是技术专家，又能管理团队，还有著作传世。
格二 · 紫府同宫 大吉·权贵
组成：紫微 + 天府 同宫坐命（多在寅/申二宫）
条件：紫微（北斗帝王星）+ 天府（南斗库星）同宫，仅可能在寅、申二宫出现。紫微解厄、天府制煞，二星合力威不可挡。
含义：尊贵稳重，领袖格局。紫微主"权"，天府主"库"——有权有库，富贵双全。为人厚重有担当，天生领导之材。
现代解读：紫府同宫之人适合大型机构、政府部门、企业中高层管理。不急不躁、步步为营。
注意：紫府同宫若逢煞星冲破（擎羊/陀罗），则"权"变"专横"，"库"变"守财奴"，格局大打折扣。
典型人物意象：大企业的掌门人——手握重权且资源充沛，深谋远虑。
格三 · 日照雷门 大吉·显达
组成：太阳在卯宫坐命（卯时日出，卯为震卦雷门）
条件：太阳独坐卯宫命宫，庙旺最吉。太阳在卯如旭日东升——光芒初放、蒸蒸日上。三方得文昌文曲更添文采。
含义：旭日东升，前程似锦。为人光明磊落、热情慷慨，早年即崭露头角，一生向上走。
现代解读：日照雷门格之人适合需要"光芒"的行业——媒体、演讲、公关、教育、公益事业。天生的感染力与号召力。
最佳配合：日月并明（同时"日照雷门"+ "月朗天门"）——夫妇或合作者中各占一格，天下无敌的组合。
典型人物意象：演说家、媒体人——一站上台就自带光芒，让人不由自主信服。
格四 · 月朗天门 大吉·贵气
组成：太阴在亥宫坐命（亥为天门，太阴在亥庙旺）
条件：太阴独坐亥宫命宫，庙旺。亥为西北天门，太阴在此如明月当空——清澈明净、光华内敛。
含义：清澈明亮，贵气内藏。为人温润如玉、心思细腻，善理财、有艺术气质，一生清贵。
现代解读：月朗天门格之人适合艺术、金融、咨询、文化行业。不张扬但底蕴深厚，适合以"柔"取胜的领域。
注意：太阴属阴水，忌火星/铃星（火炎水涸）会照，否则"明月被灼"，格局破坏。
典型人物意象：优雅的艺术家或金融才女——表面温柔，内里极有主见，如水般以柔克刚。
格五 · 雄宿朝元 大吉·威猛
组成：七杀在寅宫独坐命宫（寅为朝元之地）
条件：七杀独坐寅宫。七杀为将星，在寅宫得"木"生"金"（寅属木，七杀属金），刚猛之力有滋养之根。
含义：威猛出群，将帅之才。七杀在寅如猛虎归山——气场强大、敢作敢当、临危不惧。
现代解读：雄宿朝元格之人适合军警、体育竞技、创业、外科医生等需要"决断力"和"行动力"的领域。
注意：七杀刚猛，若无吉星调和（如文昌文曲），易孤军奋战、人际关系紧张。
典型人物意象：特种兵指挥官——独当一面、杀伐决断，是危机中最可靠的人。
格六 · 明珠出海 大吉·光明
组成：太阳在卯 + 太阴在亥 + 命宫在未（日月夹命）
条件：太阳在卯宫、太阴在亥宫（日月均庙旺），命宫在未宫。日月从两侧夹照命宫，如双灯照耀。
含义：光明显达，一生顺遂。日月为天地间最明亮的二星，同时夹命——贵不可言，名利双收。
现代解读：明珠出海格极为罕见，有此格局者往往在社会上享有盛名，适合公众人物、政治家、文化名人。
精妙之处：此格同时满足"日照雷门"和"月朗天门"——日月并明，阴阳平衡，是最为理想的格局之一。
典型人物意象：德高望重的社会名流——白天光明磊落，夜晚宁静致远，全天候受人敬仰。
格七 · 火贪格 横发·暴富
组成：火星 + 贪狼 同宫或会照（命宫或财帛宫为佳）
条件：火星与贪狼同宫，或三方会照。火星为"突发"，贪狼为"欲望+交际"——火贪相遇，如烈火烹油。
含义：暴发横财。火贪格是紫微斗数中最著名的暴富格局——来财迅猛，但去也匆匆。
现代解读：火贪格的人容易在投机、创业、新兴行业中获得爆发式财富。但需注意"来得快去得快"，若无禄存/化禄守住，钱财如水过沙。
最佳宫位：火贪在财帛宫 → 自身赚钱暴发；在命宫 → 个人能力爆发；在田宅宫 → 房产暴富。
典型人物意象：抓住风口一夜暴富的创业者——靠胆识和时机，一跃而起。
格八 · 铃贪格 暗发·蓄富
组成：铃星 + 贪狼 同宫或会照
条件：铃星与贪狼同宫会照。与火贪不同——铃星为"暗火"，慢性积累；贪狼为"欲望"——铃贪发力慢但更持久。
含义：暗中积蓄，厚积薄发。铃贪不如火贪暴烈，但财富更为持久稳固，属于闷声发大财型。
现代解读：铃贪格之人适合长线投资、实业经营、稳健创业。不如火贪来得快，但守得住。
火贪 vs 铃贪：火贪如火山爆发——来得猛；铃贪如地热温泉——来得慢但源源不断。
典型人物意象：低调的实业家——不声不响地积累财富，多年后一鸣惊人。
格九 · 禄马交驰 奔波·富足
组成：禄存 + 天马 同宫或三合会照
条件：禄存与天马同宫或会照。禄存主"财富稳定"，天马主"奔波变动"——禄马交驰 = 动中求财。
含义：奔走得财，越动越富。此格之人不适合坐守，越往外跑、越奔波，财运越旺。
现代解读：禄马交驰格最适合贸易、物流、销售、外交、跨国业务等需要"走动"的行业。坐办公室反而压制财运。
精妙之处：若禄马+太阳庙旺→国际贸易/远洋；禄马+文昌文曲→文化传播/出版。
典型人物意象：走遍全球的贸易商——足迹所至，财源随之而来。
格十 · 府相朝垣 贵格·辅佐
组成：天府 + 天相在三方四正会照命宫
条件：天府与天相在三方会照命宫。天府为"库"，天相为"印"——一库一印，如宰相辅佐帝王。
含义：辅佐周全，格局方正。府相朝垣之人稳重可靠、办事周全，是天生的二把手或幕后运作高手。
现代解读：府相朝垣格适合政府机关、大型企业中层管理、幕僚、顾问、总助等角色。虽不居C位，却是真正的实权人物。
最佳归位：天府在事业宫、天相在命宫 → 以辅佐之才得领导重用；天府在命宫、天相在财帛 → 理财周全。
典型人物意象：帝王背后的丞相——运筹帷幄之中，决胜千里之外。

五、故事卡

格局 ≠ 命运定局

📖
格 局 不 是 命 运 的 判 决 书

唐朝有一位命理师，名唤袁守诚。一日，泾河龙王化为人形前来问卦，袁守诚观其命盘后说："阁下命宫空宫无主星，三方煞星围困——按格局论，乃下等之命。"

龙王大怒，拂袖而去。《西游记》中这一段，常被后人当作"格局无用论"的佐证——一个空宫之命，何以便判为下等？

但故事另有下半段：泾河龙王虽是空宫之命，但他是龙。龙，天生便有腾云驾雾之能、翻江倒海之力——这些是任何命盘格局都无法涵盖的。命盘看得见星曜，看不见龙身。

格局管的是星曜的排列，管不了你是谁。

再讲一个真实的故事：

明代有一位书生，命宫主星天同落陷，被擎羊、陀罗夹制——按五等分类，属于"弱格"。三十岁之前，他屡试不第，穷困潦倒，似乎应验了弱格之命。

然而他并未认命。他转而潜心研究水利，遍历山川河流，著成一部《水经注》般的水利著作。后被朝廷重用，治理黄河，造福万民，青史留名。

他的命盘没有变——天同依然落陷，擎羊陀罗依然夹制。但他的大限走到了强运，且他选对了一生的事业方向。弱格+强运+选对路 = 逆天改命。

格局三定律：

① 格局是先天地图，不是GPS导航——它告诉你地势高低，但不规定你走哪条路。

② 格局的一半在天，一半在人——同样"火贪暴富格"，有人暴富后挥霍一空，有人暴富后经营成百年基业。

③ 大限流转是格局的"开关"——弱格逢强运 = 逆袭，强格逢弱运 = 蛰伏。人生是一段一段的，不是一句话概括的。

「 格 局 是 星 图 ，不 是 星 座 —— 它 描 述 你 ，但 不 定 义 你 。」

—— 紫微斗数古训新解

六、格局进阶

破格与救格 · 格局不是一成不变的

破格——格局的"毒药"

以下因素可破坏已成立的格局，称为"破格"：

破格因素影响机理示例
地空 / 地劫虚空劫难，格局之力被"掏空"三奇嘉会+地空 = 才华无法落地
化忌冲破能量逆转，吉祥变阻滞紫府同宫+廉贞化忌 = 权贵变官司
擎羊 / 陀罗刑伤拖延，格局之力被"切割"月朗天门+擎羊 = 贵人变小人
火星 / 铃星暴烈暗火（贪狼除外），破坏祥和明珠出海+火星 = 光芒过于刺眼招祸
主星落陷格局核心星曜无力，有名无实太阳落陷在酉≠日照雷门，反成败局

救格——格局的"解药"

以下因素可拯救或改善已破损的格局，称为"救格"：

救格因素作用机理示例
左辅 / 右弼贵人助力，补格局之不足弱格+左右拱照 → 遇贵人扶持逆袭
文昌 / 文曲学识才华，以智补弱空宫+昌曲 = 以学问立身，不受环境左右
天魁 / 天钺天降贵人，关键时刻得助破格+魁钺 = 绝处逢生
化禄 (非格局原配)额外的财运机缘注入弱格+化禄入财帛 = 财运拉高整体格局
大限走到强运运势补先天，十年翻身空宫+大限太阳庙旺 = 十年光明显达
宫位自化吉自身内在调适机制命宫自化科 = 以人格魅力弥补格局不足
核心认知：格局不是"打死"的。破格未必凶——火贪格本就是"煞星+主星"的破格变格局，破中有立。
救格也未必万全——辅星只能"改善"而无法"改变"格局底色。真正的救格，在于后天修为 + 大限流转 + 正确选择。

七、格局实战思路

从理论到盘面 · 格局断命的正确姿势

Step 1：打开命盘，先不看格局——只看命宫主星+三方四正，建立对命主的第一直觉。
Step 2：查阅十大格局，逐一比对——不要求100%符合，80%近似即可参考。
Step 3：若有多格局并存——取最强者为主格，其余为辅助参考。
Step 4：审大限——当前大限主星是否与格局主星呼应？呼应则格局启动，不呼应则格局休眠。
Step 5：给命主建议时——说格局的优势（方向指引），说破格的风险（警示），不说"你就是这个命"（宿命论）。
Step 6：最后一定要加一句——"格局是地图，路是你自己走的。"
