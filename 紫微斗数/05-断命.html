第一步 · 立根基

核心任务：看命宫及三方四正（命宫→财帛→官禄），判断命格强弱与层次。

判断要点

  • 命宫主星：十四主星中何星坐守？单星还是双星？
  • 庙旺利陷：星曜落入何地支宫位？庙旺则强，落陷则弱
  • 三方四正：命宫/财帛/官禄+对宫迁移宫的星曜组合
  • 辅佐煞曜：左右昌曲魁钺（吉辅）vs 羊陀火铃空劫（煞曜）
  • 四化引动：命宫及三方是否有生年四化？化禄/化权/化科/化忌

命格层次速判

上等命格信号：紫微/天府+左右昌曲魁钺在三方会照 → 格局高，有领导才能
中等命格信号：主星庙旺+无煞冲破 → 平稳有成
下等命格信号：主星落陷+羊陀火铃空劫夹命 → 一生多波折
注意：所谓"命无必吉、煞无必凶"，需结合整体宫位与大限判断。命宫弱但大限走得好，同样可有成就。

第二步 · 观性情

核心任务：通过命宫+福德宫+身宫判断命主性格特质与处事方式。

性情星曜速查

类型星曜性情特征
领袖型紫微/天府自尊心强、稳重、有领导欲
智谋型天机/巨门聪明善谋、口才好、心思活络
行动型武曲/七杀/破军刚毅果断、敢闯敢拼、执行力强
圆融型天同/太阴/天相温和善良、善协调、不喜冲突
才艺型贪狼/廉贞多才多艺、桃花旺、善交际
清高型太阳/天梁正直热心、有担当、好管闲事

性情判断技巧

  • 命宫为主：命宫主星决定核心性格
  • 福德宫为辅：反映内心世界、精神追求和消费观念
  • 身宫为后天：身宫（在哪个宫位）反映后天重心与行为倾向
  • 迁移宫为外显：对宫迁移——在外人面前的呈现方式
  • 四化调节：化权增强主见，化科增强文雅，化禄增强随和，化忌增强执着

第三步 · 定出身

核心任务：看父母宫+田宅宫+兄弟宫，判断原生家庭条件和早年运势。

出身判断要点

  • 父母宫：看父母社会地位、与父母缘分、文书学历运
  • 田宅宫：看祖业有无、家庭环境、房产运
  • 兄弟宫：看兄弟姐妹助力、朋友起步阶段
  • 命宫：三方有禄存/化禄 → 少年得志、家境优渥
富庶出身：田宅宫紫微/天府/禄存/化禄 → 祖业丰厚、家境殷实
书香门第：父母宫文昌文曲/天梁/化科 → 父母有文化、学历高
白手起家：田宅宫空劫/化忌、父母宫煞重 → 需靠自己打拼
家运起伏：田宅宫天机/破军 → 家运多变、可能有搬迁

第四步 · 查事业

核心任务：官禄宫+命宫+迁移宫三宫联看，判断事业方向和成就。

事业方向判断

类型核心信号适合领域
从政为官紫微/天府/太阳庙+天相+魁钺政府/国企/大型机构
经商创业武曲+贪狼/破军+禄存/化禄商业/金融/贸易
技术专业天机/七杀/破军+文昌/文曲IT/工程/科研/设计
文教艺术文昌/文曲/贪狼+廉贞+化科教育/文艺/传媒
法律咨询天梁/巨门+天相+魁钺法律/咨询/审计
医疗健康天梁+天同/太阴+昌曲医疗/养生/心理

事业运程信号

升迁佳期：紫微+化权、太阳庙旺+化禄在大限官禄宫
贵人助力：左辅右弼/天魁天钺在三方会照官禄
跳槽信号：官禄化忌/天机坐官禄 → 职业多变
事业危机：官禄宫空劫+化忌+火铃 → 事业受阻、有失业风险
成名时机：文昌/文曲+化科在大限官禄/迁移 → 名声鹊起
关键提示：官禄宫好但迁移宫差 → 有才能但不被外界认可；迁移宫好但官禄宫差 → 名气大于实力。三宫不可偏废。

第五步 · 断财运

核心任务：财帛宫+田宅宫+福德宫三宫联看，判断财运格局与理财能力。

财星等级

等级星曜组合财运特征
一等财武曲+化禄/禄存正财极旺、收入丰厚
二等财太阴庙旺+禄存善于积蓄、财富稳健增长
三等财天府+化禄善于理财、资产多元
暴发财贪狼+火星/铃星（火贪/铃贪）横发暴富但来得快去得也快
守成财禄存独坐无煞冲破稳定收入、不富不穷

财运三宫联动

财帛宫（来财）：看收入来源与挣钱能力——是正财(工资)还是偏财(投资)
田宅宫（守财）：看财富积累与资产——是能存钱还是左手进右手出
福德宫（享财）：看消费观与财路格局——是节俭还是挥霍、是享受还是焦虑
⚠ 破财信号速查：
财帛化忌 → 漏财破财 | 空劫在财帛 → 财来财去 | 火铃在财帛 → 冲动破财
田宅化忌 → 房产纠纷/存不住钱 | 福德化忌 → 为钱烦恼、消费过度
✅ 富格速查：
财帛宫+田宅宫+福德宫 三宫皆吉 → 富裕命格
禄存/化禄守财帛 + 天府守田宅 + 天同/太阴守福德 → 一生财福双全

第六步 · 观婚姻

核心任务：夫妻宫+福德宫+迁移宫三宫联看，判断婚姻质量与缘分时机。

配偶特征速查

星曜配偶特征婚姻状态
紫微/天府配偶条件好、有地位稳定但可能强势
太阳(庙)开朗大方、事业有成光明磊落、互敬互爱
太阴(庙)温柔美丽、贤惠体贴和谐美满
天同性格温和、知足常乐平淡是真
廉贞外貌出众、有魅力易有感情波折
巨门口才好、心思重多口舌争执
七杀/破军个性强烈、有魄力婚姻多变动

婚姻核心信号

优质信号：紫府在夫妻 → 配偶条件好 | 太阳太阴庙旺 → 夫妻和谐
桃花信号：贪狼(正桃花·才艺型) | 廉贞(次桃花·感性型) | 天姚(风流) | 红鸾(正缘) | 天喜(喜庆) | 咸池(烂桃花)
⚠ 婚灾信号：
夫妻宫化忌 → 婚姻关系紧张、沟通困难
廉贞化忌在夫妻 → 感情困扰、第三者问题
寡宿/孤辰在夫妻 → 晚婚或孤独感
羊陀火铃在夫妻 → 争吵、暴力、分离
✅ 婚期判断：
大限夫妻宫化禄 + 流年红鸾天喜入夫妻宫/命宫 → 婚期最强信号！
流年夫妻宫见红鸾/天喜/文昌化科 → 当年有结婚机会

第七步 · 察健康

核心任务：疾厄宫+父母宫（父疾线/文书线），判断先天体质与潜在疾病。

星曜与身体部位对应

星曜对应部位易患疾病
太阳心/眼/头部心脏病、眼疾、高血压
太阴肾/妇科/血液肾病、妇科病、贫血
巨门口/消化/呼吸口腔病、胃病、气管炎
天机肝/神经/手足肝病、神经衰弱、手足伤
武曲肺/骨骼/鼻肺病、骨折、鼻炎
廉贞血液/免疫/皮肤血液病、过敏、皮肤病
贪狼肝/生殖/泌尿肝病、生殖系统、肾病
七杀骨骼/外伤骨折、意外伤害、手术
破军生殖/泌尿妇科、泌尿系统
天梁脾胃/脊柱胃病、脊椎病

健康判断要点

  • 疾厄宫为主：坐何星曜、有无煞星冲破
  • 父疾线（父母+疾厄）：两宫对拱，看遗传病和文书运
  • 煞星入疾厄：羊陀 → 外伤手术 | 火铃 → 急性炎症 | 空劫 → 慢性消耗
  • 化忌入疾厄：身体有明显的薄弱环节
  • 命宫+疾厄同时受冲：大凶，需特别关注健康
⚠ 危疾信号：疾厄宫化忌+火铃/羊陀同宫 → 重大疾病风险
⚠ 意外信号：迁移宫七杀+擎羊 → 车祸/意外伤害
⚠ 手术信号：疾厄宫见天刑/白虎+羊陀 → 手术住院

第八步 · 排大限

核心任务：按五行局排出各十年大限所在宫位，结合大限四化分析十年运势起伏。

大限排法口诀

阳男阴女顺行、阴男阳女逆行。
从命宫起，每宫管十年。五行局定起运岁数：
水二局2岁起 | 木三局3岁起 | 金四局4岁起
土五局5岁起 | 火六局6岁起

大限分析要点

  • 大限命宫：该十年主运宫位，星曜+四化定十年基调
  • 大限四化：大限天干产生四化，叠加在原局之上
  • 大限三方：大限命宫的三方四正——该十年的财、官、迁移
  • 大限与四柱对冲：大限命宫若与生年四柱发生刑冲克害，防该大限不顺
  • 好大限标志：大限命宫主星庙旺+化禄/化权/化科+吉星会照

大限吉凶速判

大限类型核心信号运程特征
好运大限紫微/天府/太阳庙+化禄/化权事业上升、财运亨通
平运大限天相/天同+无煞冲破平稳发展、无大起伏
变动大限天机/破军/七杀多有变动、宜顺势而为
波折大限巨门+化忌/廉贞化忌+煞重口舌是非、波折不断
桃花大限贪狼+红鸾/天喜/咸池桃花旺、情感事件多
财运大限武曲+化禄/禄存守大限财帛财运高峰期

第九步 · 断流年

核心任务：结合流年太岁、小限、斗君，精准定位当年吉凶事件。

流年论断体系

三大流年工具：
① 流年太岁：以当年干支定流年命宫，看太岁所在宫位的星曜四化
② 小限：以生年年支为起点，男命逆行/女命顺行（每岁一宫）
③ 斗君：定流年正月之宫——从流年太岁宫起正月，逆数至生月，再顺数至生时即为斗君（正月宫位）

流年判断权重

流年太岁 → 最重要（70%）：看当年整体运势
小限 → 辅助（20%）：与太岁同参，加强判断
斗君 → 细化（10%）：定正月后逐月顺数，看具体月份

斗君 · 流月定位法

斗君起法

步骤一：以流年太岁所在宫位为起点（当作正月）
步骤二：逆数（逆时针）至命主出生月份所在宫位
步骤三：从该宫位顺数（顺时针）至出生时辰所在宫位
结果：该宫即为当年斗君（正月宫位）
逐月：斗君宫 = 正月 → 下一宫 = 二月 → 依次顺数至十二月

小限起法

男命：以生年年支所在宫位为1岁起点，逆数（逆时针）→ 2岁在下一宫 → 3岁再下一宫……
女命：以生年年支所在宫位为1岁起点，顺数（顺时针）→ 2岁在下一宫 → 3岁再下一宫……
注意：小限主要作为流年太岁的辅助参考，两者吉凶同参。若流年太岁吉而小限凶，说明虽有困难但总体向好；反之亦然。

第十步 · 汇总论

核心任务：将前九步结论整合，给出全面命理总结与建议。

汇总框架

  1. 命格总结：命宫强弱+格局层次，一句话概括
  2. 性格标签：核心性格特质（2-3个关键词）
  3. 事业路径：最佳行业方向+发展时机
  4. 财运特征：财源模式+注意事项
  5. 婚姻状况：配偶特征+婚期+注意事项
  6. 健康关注：薄弱环节+保健建议
  7. 大运曲线：各十年运程起伏+关键转折点
  8. 当前流年：本年重点关注事项
  9. 趋吉避凶建议：具体可操作建议

汇总原则

① 先总后分：先说整体命格层次，再分项细论
② 吉凶并陈：有吉说吉、有凶说凶，不偏不倚
③ 轻重有序：最突出的特点先说（无论吉凶）
④ 给出建议：不止于论断，还要给出趋避建议
⑤ 留有余地：命理是趋势而非定数，"一命二运三风水四积德五读书"
善断者，不在星多，而在抓住关键。一个命盘，能说准最核心的三五件事，胜过面面俱到却事事不准。——斗数断命心法

第三部分 · 大限流年推算详解

大限+小限+流年+斗君 · 四层运限体系

一、大限推算（十年运）

大限起法

起运岁数：由五行局决定 → 水二局2岁、木三局3岁、金四局4岁、土五局5岁、火六局6岁
运行方向：阳男阴女 → 顺行（顺时针）；阴男阳女 → 逆行（逆时针）
每宫十年：从命宫开始，每顺时针/逆时针走一宫管十年
阴阳判定：生年天干 → 甲丙戊庚壬为阳年；乙丁己辛癸为阴年

大限四化

每个大限所在宫位的天干产生该大限的四化飞星（禄权科忌），叠加到原局星曜之上。

示例：大限命宫在甲辰宫 → 甲天干四化 = 廉贞化禄 + 破军化权 + 武曲化科 + 太阳化忌 → 该十年这些星曜所在宫位被引动。

二、小限推算（岁运）

小限起法

起点：以生年年支所在宫位为1岁
男命：逆行（逆时针）→ 每增一岁走一宫
女命：顺行（顺时针）→ 每增一岁走一宫
作用：小限配合大限和流年太岁，三方共参增强判断

小限+大限+流年联用法

三合一判断法：
① 大限定十年基调（大方向）→ ② 流年太岁定当年主事（应期）→ ③ 小限定细节（辅助验证）
三重信号重合 → 事件发生的概率极高
例：大限夫妻化禄（婚运十年来临）+ 流年红鸾入命（今年桃花旺）+ 小限到夫妻宫（岁运亦到）→ 婚期不可挡！

三、斗君推算（流月运）

斗君完整推算法

第1步：以流年太岁所在宫位作为正月（寅月）的起点
第2步：从该宫逆数（逆时针）至命主出生月份所在宫位
第3步：从该宫顺数（顺时针）至命主出生时辰所在宫位
第4步：所得宫位即为当年斗君——该宫为正月，下一宫为二月，依次顺数至十二月

斗君使用示例

例：命主生于五月午时，求2024甲辰年斗君。
① 2024甲辰年太岁在辰宫（当作正月起点）
② 从辰宫逆数至五月 → 辰(正)→卯(二)→寅(三)→丑(四)→子(五) ← 停在子宫
③ 从子宫顺数至午时 → 子(子)→丑(丑)→寅(寅)→卯(卯)→辰(辰)→巳(巳)→午(午) ← 停在午宫
④ 午宫 = 斗君（正月） → 未宫(二月)→申(三)→酉(四)→戍(五)→亥(六)→子(七)→丑(八)→寅(九)→卯(十)→辰(十一)→巳(十二)

四、三代四化叠加体系

核心原理：原局四化（根基）+ 大限四化（十年引动）+ 流年四化（当年触发）= 三重叠加定吉凶。

叠加规则：
① 三代四化同星同宫 → 事件力量极强，几乎必然发生
② 三代四化互冲（如本命化禄被流年化忌冲）→ 好事被打断
③ 原局无四化 → 以大限四化为主；大限无四化 → 以流年四化为主
④ 禄权科忌相叠（如同宫同时有禄+科）→ 事件复合、层次丰富

实战口诀："原局定有无，大限定趋势，流年定应期。三化同宫事必成，反向相冲事必败。"

第五部分 · 断命心法荟萃

从技法到心法 · 历代口诀与实战经验

🎯 斗数断命十六字真言 总纲
宫位定人事 星情定吉凶
四化寻契机 行运看变化
此十六字贯穿整个断命过程，是紫微斗数论断的最高心法。无论面对何种命盘、何种问题，始终以四句话为纲领：先看宫位确定论什么，再看星情判好坏，三看四化找触发点，四看大限流年定时间。四者缺一不可，顺序不可颠倒。

断命十要

  1. 格局为先：先看命宫三方四正格局，定命格层次
  2. 庙陷为要：星曜庙旺利陷决定力量强弱
  3. 吉煞并看：有吉看吉、有煞看煞，不偏废
  4. 四化为机：四化是变化的关键引信
  5. 夹宫莫忘：两邻宫对中间宫的夹辅/夹制作用
  1. 三代叠参：本命+大限+流年三层叠加
  2. 宫位互通：一宫有事、对宫/三合皆受影响
  3. 星宫配合：星为主、宫为用，星宫不可分离
  4. 活盘活用：同一命盘可用于测他人他事（ATP）
  5. 留有余地：命理是趋势，不是绝对定数

断命常见误区

❌ 见煞就断凶：煞星须看整体配置——七杀+昌曲可为"文武全才"，不可单星论命。
❌ 见吉就说好：吉星过重也可能"过犹不及"——多禄存反而懒惰、化禄过重反而不珍惜。
❌ 只看原局不看大限：原局差的命盘，走好大限照样有成就；反之，好命盘走坏大限也会低谷。
❌ 迷信单一信号：任何论断都需要"三重验证"——至少三个宫位/星曜/四化信号指向同一结论，才能下定论。
