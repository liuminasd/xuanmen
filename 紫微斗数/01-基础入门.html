一、阴阳五行 —— 紫微斗数的哲学根基

1. 阴阳：宇宙万物的二分法

阴阳学说把宇宙万物归为阴阳两大性质，一切事物的形成、变化和发展，都是阴阳二气运动与转换的结果。这不是简单的"好坏"二分——阴阳是相互依存、相互转化的。

🔑 核心规律（直接影响星曜论断）

同性相生（阳生阳、阴生阴）→ 生力大，推动力强
异性相生（阳生阴、阴生阳）→ 生力小，温和滋养
同性相克（阴克阴、阳克阳）→ 克性大，真克·无情之克
异性相克（阴克阳、阳克阴）→ 克性不大，有情之克，只是适度管制

💡 为什么重要？论断两颗星的关系时，同性相克=严重冲突，异性相克=温和摩擦。这在看夫妻宫、官禄宫时尤为关键。

2. 五行：五种基本物质的生克循环

🔄 相生循环：金→水→木→火→土→金
金熔成水 · 水浇树木 · 木可燃火 · 火烧成土 · 土中藏金
⚔ 相克循环：金→木→土→水→火→金
金可伐木 · 木可破土 · 土可堵水 · 水可灭火 · 火可熔金

在紫微斗数中，每颗星曜都有五行属性。两颗星同宫或对宫时，它们之间的生克关系决定了互动的好坏。例如：武曲（金）+ 天机（木）= 金克木，武曲压制天机的灵动性。

3. 五行旺衰：星曜力量的"季节"

当令者旺，令生者相，生令者休，克令者囚，令克者死。（令=当季的五行：春木、夏火、秋金、冬水、四季末土）
季节旺相休囚死
春（木令）木火水金土
夏（火令）火土木水金
秋（金令）金水土火木
冬（水令）水木金土火

4. 长生十二神

长生→沐浴→冠带→临官→帝旺→衰→病→死→墓→绝→胎→养

长生/冠带/临官/帝旺 = 旺相 ✓ | 沐浴 = 破败 △ | 衰/病/死/墓/绝 = 衰落 ✗ | 胎/养 = 温养 ○
阶段小结：阴阳→五行→旺衰→长生十二神，四层递进。核心逻辑：星曜的五行属性 + 所在宫位的季节状态 = 星曜的实际力量。

三、六十甲子与纳音五行

六十甲子

天干10个 × 地支12个 = 120种组合 → 但必须阳干配阳支、阴干配阴支 → 只有60种 = 六十甲子。用于纪年、纪月、纪日、纪时——即四柱八字的时间坐标系统。

纳音五行速算法

🔑 纳音速算法（必背）

天干配数：甲乙=1，丙丁=2，庚辛=3，戊己=4，壬癸=5
地支配数：子丑午未=1，寅卯申酉=2，辰巳戍亥=3
干支数相加 → 若>5则减5 → 余数：1木 2金 3水 4火 5土

例：戊戍 → 戊=4 + 戍=3 = 7 > 5 → 7-5=2 → 2=金 → 戊戍纳音为金

💡 排盘核心链条：命宫干支 → 纳音五行 → 五行局数（水2/木3/金4/土5/火6）→ 配合农历生日 → 确定紫微星落宫。这是整个排盘最核心的计算链条。
