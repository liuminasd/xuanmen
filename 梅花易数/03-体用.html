体用生克精义

体用分明 · 生克有准 · 旺衰定乾坤

一、体用总纲 — 断卦之第一要义

梅花易数断卦，首分体卦与用卦。 体用之分，如同棋局之"我方"与"对方"，亦即主客之道——体为主、为己、为问卦之人及所问之事的主体； 用为客、为彼、为作用于主体之外部力量。体用明，则吉凶可断；体用淆，则全盘皆乱。

1.1 体用基本定义

项目体 卦用 卦
定义 卦中没有动爻的经卦 卦中有动爻的经卦
象征 "我" — 问卦者自身、主体、根基 "事" — 所问之事、对方、外部环境
角色 如一国之君、一身之主，不动之根本 如外来之使、变动之机，生克之力源
五行指向 体卦的五行代表"我方的状态" 用卦的五行代表"外部的力量"
吉凶指向 体宜旺、宜受生、宜比和 用生体为吉，用克体为凶

1.2 如何确定哪一卦有动爻

一个六爻别卦由上卦（外卦，4-5-6爻）与下卦（内卦，1-2-3爻）两个经卦组成。
动爻所在的三爻组即为用卦，另一组即为体卦。
  1. 起卦得本卦（六爻别卦），确定动爻位置
  2. 动爻在 1 / 2 / 3 爻 → 下卦为用卦，上卦为体卦
  3. 动爻在 4 / 5 / 6 爻 → 上卦为用卦，下卦为体卦
  4. 体卦保持不动；用卦因动爻阴阳反转而变为变卦中对应的经卦
根本口诀：动者为用，不动为体。体为己身之主，用为外事之机。

1.3 特殊情况判断

特殊情况体用判断规则说明
静卦（无动爻） 上卦为体，下卦为用 无动爻时，取外卦为体（主）、内卦为用（客），以上下尊卑定体用
两个动爻 以初动爻所在卦为用 两爻皆动时，取位置较下（靠近初爻）的动爻所在经卦为用卦，另一卦为体卦
三个及以上动爻 以多数动爻所在卦为用 上下卦中，哪一经卦含更多动爻即为用卦；若相等则上卦为体、下卦为用
六爻皆动（全变） 上卦为体，下卦为用 全变则无所谓动静之分，回归上下尊卑之序；但极为罕见，当结合互卦综合判断
代人占卜 体为所代之人，用为事 代人占卜时，体卦代表所代之人（非占卜者自己），不可机械理解为"体即占者"
要点：体用并非绝对的"我"与"事"，而是一对相对关系——体为被判断的主体， 用为作用于主体的力量。理解这一层，方能灵活运用于各类占问场景。

二、五大生克格局 — 吉凶之纲

体卦与用卦的五行关系，决定了事物发展的基本吉凶方向。五行生克共有五种基本关系， 映射到体用之间形成五大格局，由吉至凶排列如下：

2.1 格局总表

格局 五行关系 吉凶等级 断语 详细解释
用生体 用卦五行 → 生 → 体卦五行 大吉 万事顺遂 外部力量滋养、扶助我方。如得天助，事事得人相助、逢凶化吉。
例：体为震木，用为坎水 → 水生木，大吉。
体用比和 体卦五行 = 用卦五行 吉 事事顺畅 内外合一、同心同德。体用同气，无克无伤，诸事平顺，宜守成。
例：体为离火，用亦为离火 → 比和，吉。
体克用 体卦五行 → 克 → 用卦五行 中吉 费些周章 我方能克制对方，但需付出努力。事虽可成，须主动争取，不可坐等。
例：体为乾金，用为震木 → 金克木，中吉。
体生用 体卦五行 → 生 → 用卦五行 小凶 有耗有伤 我方之气外泄以生对方，消耗自身。事虽有成而伤己，或付出多而回报少。
例：体为离火，用为坤土 → 火生土，小凶。
用克体 用卦五行 → 克 → 体卦五行 大凶 万事不祥 外部力量克制我方，百事难成。诸事不可为，宜静不宜动，当以守为进。
例：体为巽木，用为兑金 → 金克木，大凶。

横行为体卦五行，竖列为用卦五行。交叉处即为体用格局。

体=金体=木体=水体=火体=土

建议熟记五行生克关系（金生水、水生木、木生火、火生土、土生金；金克木、木克土、土克水、水克火、火克金），不依赖表格。

根本原则：凡是有利于体卦（生体 / 比和）则吉； 凡是有害于体卦（克体 / 泄体）则凶。

三、体用生克口诀

用生体兮大吉昌，事事顺遂得天光； 体用和兮事事畅，内外同心无灾殃； 体克用兮费周章，事虽可成须自强； 体生用兮有耗伤，泄气劳心损力量； 用克体兮事不祥，诸般谋划尽成汤。
记诵提示：此口诀按由吉到凶排列，五句对应五大格局。 每日诵读三遍，七日可脱口而出。断卦之时，心中默念此诀，格局立判。

四、旺衰修正法则 — 同格不同命的关键

体用生克格局决定了吉凶的大方向，但旺衰（即卦气强弱、时令盛衰） 则决定了吉凶的程度。同一格局，因旺衰不同，结果可能天差地别。 这是初学者最容易忽略、却最重要的一层。

4.1 旺衰判断标准

月令（最重） 卦之五行得月令生扶（当令/相令） 卦之五行被月令克制（囚令/死令）
卦气 卦处其本位或旺位（如震巽在春、离在夏） 卦处衰位（如坎在夏、离在冬）
动爻趋向 动爻生体 / 动爻化出之卦生体 动爻克体 / 动爻化出之卦克体
党势 体党多（互卦、变卦中多生体或比和者） 用党多（互卦、变卦中多克体或泄体者）

五、党势之理 — 旺衰背后的力量博弈

判断旺衰时，单看体用二卦的月令往往不够。还需要观察互卦、变卦中 各经卦与体卦的关系——这就是党势。体卦周围的"盟友"（体党）越多越旺， "敌人"（用党/克体之卦）越多则越衰。

5.1 党势三原则

体党多 → 体旺而吉

互卦、变卦中出现与体卦同五行或生体卦五行的经卦越多，体卦越强。

同五行 = 比和帮身 生体五行 = 外援相助

例：体为震木，互卦见巽木（比和）、变卦见坎水（生木）→ 体党强旺。

用党多 → 克体之力强

互卦、变卦中出现克体卦五行或体生之五行（泄体）的经卦越多，体卦越受克制。

克体五行 = 直接攻击 泄体五行 = 暗中消耗

例：体为离火，互卦见坎水（克火）、变卦见坤土（泄火）→ 体受围攻。

连环生克 — 复杂博弈

当互卦、变卦、用卦之间形成连环相生或连环相克时，需要画出完整的生克链进行分析。

A生B生C → 终归于C A克B克C → 隔位不克^

^隔位不克存争议，实战中灵活判断。连环生克中最终落点在体卦则吉，在克体之卦则凶。

5.2 党势分析步骤

  1. 列出本卦的体卦和用卦及其五行
  2. 列出互卦的上卦和下卦及其五行（互卦从本卦中间四爻而来）
  3. 列出变卦的上卦和下卦及其五行（将本卦动爻阴阳反转而来）
  4. 统计：所有卦中，生体及与体比和者 = 体党；克体及体之所生（泄体）者 = 用党/敌党
  5. 比较体党与用党的数量和旺衰（得月令者权重加倍）
  6. 综合判断：体党压倒性优势 → 虽凶可解；用党压倒性优势 → 虽吉亦危
党势简诀：
体卦总强度 ≈ 月令旺衰系数 + 体党数 − 敌党数
（两者皆以得月令之党权重为高）
要诀：党众者胜，孤寡者败。体卦若得众党护持，虽遇用克亦有转机； 体卦若孤立无援，虽得用生亦难大成。

六、故事化案例 — 同格局，不同命

以下两个案例，体用生克格局完全相同（皆为"用生体"之大吉格）， 但因旺衰形势截然不同，最终结果一成一败、一喜一悲。 这正是旺衰修正法则在实战中的生动体现。

案例甲 · 春月求职 · 体旺用衰 → 大吉应验

故事背景

癸卯年正月（寅月·春·木旺），青年张某欲应聘某大公司。 心烦意乱之际，以数字法起卦，随口报数：6、4、5。

起卦过程

第1数 6 → 6÷8 余6 → 坎 ☵（水）→ 上卦
第2数 4 → 4÷8 余4 → 震 ☳（木）→ 下卦
第3数 5 → 5÷6 余5 → 第五爻动
得卦：䷧ 雷水解（上坎水、下震木），五爻动。

体用判断

第五爻属于上卦（4/5/6爻为上卦）→ 上卦坎为用卦，下卦震为体卦。
体卦：震 ☳ 木。用卦：坎 ☵ 水。
水生木 → 用生体 = 大吉格！

旺衰分析

正月 = 寅月 = 春季。春木旺 → 体卦震木得月令旺气（旺·当令）。
春水休 → 用卦坎水在春季为休（衰退）。
体旺 + 用衰 → 吉上加吉，如虎添翼。

党势简判

五爻阳变阴：上卦坎☵变坤☷ → 变卦为䷏ 雷地豫（上坤土、下震木）。
变卦下卦震木 → 与体卦比和（体党+1）。
互卦（取本卦中间四爻）：二三四爻为离☲，三四五爻为坎☵ → 互卦䷾水火既济。
体党虽不多，但体得月令旺气，压倒性优势。结论：大胆应聘，必有所成。

实际结果

张某信心十足前往面试，三场皆顺，当场获得录用通知。入职后上司器重，同事友善， 半年即升主管——果然得水生木之势，遇贵人相助，事业发展迅猛。

卦象总结

  • 本卦䷧ 雷水解
  • 体卦震 ☳ 木
  • 用卦坎 ☵ 水
  • 生克水生木
  • 格局用生体·大吉
  • 月令寅月·春
  • 体旺衰旺（当令）
  • 用旺衰休（衰退）
  • 修正吉上加吉
  • 建议大胆进取
案例乙 · 秋月求职 · 体衰用旺 → 吉而不吉

故事背景

同年七月（申月·秋·金旺木死），青年李某同样欲求职。 巧合的是，他亦以数字法起卦，竟不约而同报出了 6、4、5——与张某完全相同的数字。

起卦过程

第1数 6 → 坎 ☵（水）→ 上卦
第2数 4 → 震 ☳（木）→ 下卦
第3数 5 → 第五爻动
得卦：䷧ 雷水解（同卦同动爻）。

体用判断

第五爻动 → 上卦坎为用，下卦震为体。
体震木，用坎水。
水生木 → 用生体 = 大吉格！
——与张某完全相同的大吉格局。

旺衰分析

七月 = 申月 = 秋季。秋金旺 → 金克木，体卦震木在秋季处于"死"地（极衰）。
秋金生水 → 用卦坎水在秋季为"相"（次旺）。
体衰（死）+ 用旺（相）→ 虽有"用生体"之名，却无"真生"之力。

党势简判

变卦同为䷏雷地豫，互卦同为䷾水火既济。但在申月之下：
变卦下震木 → 与体比和但同在"死"地 → 虽为体党却无力相助。
互卦上坎水 → 在秋为"相"（旺），但水为用党之源，更助对方之势。
体衰至极，虽有比和之党亦如枯木——结论：格局虽吉，吉而不应，反见波折。

实际结果

李某满怀信心连投五家公司，竟无一回应。唯一进入面试的一家，也在终面时 因"岗位取消"而告吹。前后奔波两月，心力交瘁，空手而归——正如卦象所示： 枯木逢水亦难生，秋金当令万事休。

卦象总结

  • 本卦䷧ 雷水解
  • 体卦震 ☳ 木
  • 用卦坎 ☵ 水
  • 生克水生木
  • 格局用生体·大吉
  • 月令申月·秋
  • 体旺衰死（极衰）
  • 用旺衰相（次旺）
  • 修正吉而不吉
  • 建议静待时机
