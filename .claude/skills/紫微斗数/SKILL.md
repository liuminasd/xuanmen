精通紫微斗数的星曜、宫位、四化、格局、大限流年与断命技法。

## 一、核心心法：三大支柱

> **「宫位定人事，星情定吉凶，四化寻契机，行运看变化。」**

推命只有三个要素：**星情、宫位、四化**。其中四化是唯一具有**动态特性**的表征——

> **「不知四化，何以论命。」**

### 三大流派互补

| 流派 | 关注重点 | 核心功用 |
|------|----------|----------|
| **三合派** | 星曜组合、三方四正、格局 | 定格局与先天特质 |
| **飞星派** | 四化在宫位间的能量流动 | 追大限流年变化 |
| **自化** | 宫位内部能量自我转化 | 补足心理层面与细节 |

实务解盘 = 三合定调 → 飞星抓时机 → 自化看心态

## 二、十四主星精要

### 北斗星系（刚·主动·逆时针安星）

紫微 → 天机 → 太阳 → 武曲 → 天同 → 廉贞

| 主星 | 五行 | 一句话秘诀 | 核心特质 |
|------|------|-----------|----------|
| **紫微** | 阴土 | 注定站在中央，有格局有担当 | 帝王星，尊贵自尊、领导力、孤傲 |
| **天机** | 阴木 | 脑子永远比嘴快 | 智星，善谋寡断、变化快、思虑多 |
| **太阳** | 阳火 | 把光都给了别人 | 奉献星，热情外放、博爱、重面子 |
| **武曲** | 阴金 | 认准了就不回头 | 财星，刚毅果断、执行力强、刚直 |
| **天同** | 阳水 | 只想把日子过舒服 | 福星，温和享受、随和、懒散 |
| **廉贞** | 阴火 | 最复杂也最有生命力 | 次桃花，刚烈多变、才华与是非并存 |

### 南斗星系（柔·和顺·顺时针安星）

天府 → 太阴 → 贪狼 → 巨门 → 天相 → 天梁 → 七杀 → 破军

| 主星 | 五行 | 一句话秘诀 | 核心特质 |
|------|------|-----------|----------|
| **天府** | 阳土 | 越老越稳，厚积薄发 | 库星，包容稳重、善于理财管理 |
| **太阴** | 阴水 | 心里装着一片海 | 月亮星，敏感细腻、情感丰富、善理财 |
| **贪狼** | 阳木 | 什么都想试一试 | 桃花主，多才多欲、交际手腕强、缺定力 |
| **巨门** | 阴水 | 成也一张嘴，败也一张嘴 | 暗星，口才好、是非多、善于分析 |
| **天相** | 阳水 | 最可靠的幕后之人 | 印星，辅佐周全、公正稳重、需依托明主 |
| **天梁** | 阳土 | 眼里揉不得沙子 | 荫星，老成慈悲、清正有原则、长寿 |
| **七杀** | 阳金 | 冲在最前面 | 将星，威猛决断、敢拼敢冲、孤独 |
| **破军** | 阳水 | 永远在打破规矩 | 耗星，破旧立新、敢作敢为、不稳定 |

### 关键认知
- 主星**需四化激活**才显吉凶（如太阳化权主贵，化忌主劳碌）
- 主星**需宫位定位**，同一星在不同宫作用迥异
- 主星**需会照制衡**，星与星之间的牵引制衡才让命盘"活"起来
- **天府、天相、七杀全无四化**，这三颗星不受天干化曜影响

四化是**能量的流转**，源自月相纳甲，对应四季五行：

| 四化 | 季节 | 五行 | 先天数 | 核心含义 |
|------|------|------|--------|----------|
| **化禄** | 秋 | 金 | 四九 | 缘起·财富·机遇·满足·丰饶 |
| **化权** | 夏 | 火 | 二七 | 掌控·权力·竞争·强势·执行力 |
| **化科** | 春 | 木 | 三八 | 名声·学识·贵人·才华显现 |
| **化忌** | 冬 | 水 | 一六 | 收敛·阻碍·执着·业力·亏欠 |

### 四化运用的层次

| 层次 | 含义 | 影响 |
|------|------|------|
| **生年四化** | 先天垂象，出生年天干决定 | 影响最大、最长，为「体」|
| **大限四化** | 十年运势流转 | 启动生年四化的能量 |
| **流年四化** | 当年运势应期 | 为「用」 |
| **宫位自化** | 宫内星曜自行产生的四化 | 内在心理与自我调节 |

### 四化深层奥义

**化禄**：
- 为「缘起」、欲望的因源
- 「禄藏财中，禄随忌走」——禄忌同参方能见得失全貌
- 化禄入迁移宫：动中求财，离乡发展更有利

**化权**：
- 本质为「小忌」——虽带来压迫感，但终究是有利的磨砺
- 在夫妻宫需细分：女星化权→配偶强势，男星化权→自身主导

**化科**：
- 「一科化二忌」——水生木之理
- 35岁前人荫我，以后要荫他人

**化忌**：
- 生年忌是**业力**，命宫干忌是**自找的**，岁限干忌是**运势**
- 忌是示警，主变动不安、转机、得失、亏欠
- **忌入辰戌丑未四库位**，反为「忌入库」，有收藏聚财之象

### 四化碰撞法则

| 碰撞 | 效应 |
|------|------|
| 禄权碰撞 | 丰盛横发，名利双收 |
| 禄科碰撞 | 因名得利，文人水平高 |
| 禄忌碰撞 | 运势变化大，时起时伏 |
| 权科碰撞 | 有专门技能，技师类 |
| 权忌碰撞 | 事起仓促，来去匆匆 |
| 科忌碰撞 | 拖拉不定，难彻底解决 |
| 双禄/双权/双科/双忌 | 加重原有作用 |

## 七、三方四正与大限流年

### 三方四正
- **三合方**：命宫的三合宫 = 命宫 + 财帛 + 官禄（地支三合：申子辰/亥卯未/寅午戌/巳酉丑）
- **对宫**：相隔六宫的对冲关系，互为表里
- **夹宫**：前后两宫对中间宫位的影响

### 大限流年
- **大限**：十年一变的大运（起法：五行局定起始岁数，顺逆行至各宫）
- **小限**：按生年支每年一换
- **流年**：当年太岁入宫，看四化流转
- **斗君**：流月运势

## 十、专题论断速查

### 事业论断
- **核心宫位**：官禄宫（主） + 命宫 + 迁移
- 紫微/天府在官禄 → 管理型
- 武曲/七杀在官禄 → 执行型/军警
- 贪狼/廉贞在官禄 → 交际型/艺术
- 天机/天梁在官禄 → 智谋型/顾问

### 财运论断
- **核心宫位**：财帛宫 + 田宅宫 + 福德宫（三宫联看）
- 武曲在财帛 → 正财强劲
- 太阴在财帛 → 细水长流善理财
- 禄存+化禄在财田 → 大富格
- 忌星在财帛 → 钱财有损、不聚财

### 婚姻论断
- **核心宫位**：夫妻宫 + 福德 + 迁移
- 贪狼/廉贞在夫妻 → 桃花重、感情激烈
- 天相/天同在夫妻 → 和谐但男方可能软弱
- 七杀/破军在夫妻 → 晚婚或波折
- 化忌在夫妻 → 感情有业力，需看对宫官禄的稀释

### 健康论断
- **核心宫位**：疾厄宫 + 父母宫
- 主星五行对应身体：
  - 火(太阳廉贞)→心/血 → 木(天机贪狼)→肝/胆
  - 金(武曲七杀)→肺 → 水(太阴天同)→肾
  - 土(紫微天府)→脾胃
- 煞星会照疾厄 → 对应五行部位易有疾患
