精通奇门遁甲的排盘、断局、用神取象与心法运用。

## 一、根本心法

### 由术入道

奇门遁甲的核心精髓是**从会用奇门进阶到活出奇门**。排盘法、取用诀、旺衰表、格局判皆为"渡河之筏"——筏是工具，登岸之后不可执著。

> **心法口诀**：术为渡河筏，道是彼岸土。执筏不登岸，终是水中客。

断局的三重境界：
1. **初学见山是山**：吉凶分明，按图索骥
2. **进阶见山不是山**：虚实交错，辩证分析
3. **入道见山还是山**：气机自流，一眼洞穿

### 用盘心法 — "一心一盘一事"
- 人与盘、盘与事本为一体（心、事、盘是"一"）
- **初学者愈单纯，断事愈准；学得愈杂，反而错漏增多**
- 保持初心单纯，接近"一"便接近"道"

### 法、理、情三层
**第一用法，第二用理，第三用情**——次序不可颠倒。法是章法心法，理是易理，情是人情物情。

## 七、定局与排盘

### 定局三要素

**1. 节气定阴阳遁**
- 冬至—夏至：**阳遁**（顺排）
- 夏至—冬至：**阴遁**（逆排）

**2. 三元定局数**
- 符头（甲己）配地支：
  - 子午卯酉 → **上元**
  - 寅申巳亥 → **中元**
  - 辰戌丑未 → **下元**

**3. 置闰法**
- 节气与符头错位时，通过置闰调整

### 排盘步骤

1. **布地盘**：按阴阳遁顺逆，将三奇六仪飞布九宫
2. **定值符值使**：按时柱旬首，定值符星（天盘主导星）和值使门（人盘主导门）
3. **转天盘**：值符星随天盘旋转
4. **转人盘**：值使门随人盘推移
5. **安神盘**：八神依次排布
6. **标空亡马星**：空亡（旬空之宫）、马星（驿马之宫）

## 八、断局核心框架

### 精髓原则
> **事为主，时为客**——所问之事决定哪个符号影响力最大。

### 实战断局五步

| 步骤 | 内容 | 要点 |
|------|------|------|
| **第零步** | 定核心用神 | 问财→生门+戊，问病→天芮，问工作→开门，问婚→六合+乙庚 |
| **第一步** | 看八门 | 近期吉凶，门生宫则易成，门克宫则难成 |
| **第二步** | 看天干格局 | 核心矛盾与症结，是盘局的"戏眼" |
| **第三步** | 看九星 | 长期基础，决定事情底色 |
| **第四步** | 看八神 | 无形力量加减分 |
| **第五步** | 综合串联 | 将以上信息串联成逻辑通顺的判断 |

### 四维分析框架

- **竖看四盘**：天时(九星) + 地利(地盘) + 人和(八门) + 神助(八神)
- **横看生克**：日干(求测人)与时干(所问事)的生克关系
- **时空定位**：内盘(1-4宫=近快) vs 外盘(6-9宫=远慢)
- **能量评估**：月令旺衰定吉凶力度，空亡填实、马星动应为应期

### 特格速查

| 格局 | 含义 |
|------|------|
| **伏吟** | 星门不动，事情迟缓停滞 |
| **反吟** | 星门对冲，事情反复变动 |
| **空亡** | 旬空之宫，待填实方应 |
| **入墓** | 用神入墓，能量被压 |
| **击刑** | 地支相刑，波折纠纷 |
| **门迫** | 门克宫，事情受阻 |
| **五不遇时** | 时干克日干，诸事不宜 |

### 用神心法
- 日干 = 求测人（"我"）
- 时干 = 所问之事
- 值符 = 大环境 / 主导力量
- 值使 = 事体的关键 / 执行通道
- 年干为根、月干为干、时干为梢
- **身要胜物则事易，物来胜身则事难**

## 九、学习路径

### 四阶段
1. **盘局不可不学**：熟练起局，掌握阴阳遁108局基础
2. **象义不可不悟**：将星门神仪化为鲜活的能量体，**死记不如悟**
3. **能量不可不明**：旺衰定力之大小，时令与落宫不可偏废
4. **聚焦不可不准**：凡测必有人，凡测必有事，以人定位为主

### 常见误区
- 纠结门派之争 → 本质都是"炁的变化与组合"，专注一门精透后融会贯通
- 死记类象符号 → 应以心象思维替代机械背诵
- 忽视空亡马星 → 空亡暗示转折，马星指示变动时机
- 用神选取单一 → 重大事项需综合年命、月令、格局等多维信息
