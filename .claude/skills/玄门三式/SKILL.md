**相生**：木→火→土→金→水→木（顺次而相生）

**旺相休囚死**：当令者旺、我生者相、生我者休、克我者囚、我克者死

> 五行是三大体系共通的"能量语言"。无论哪个体系，生克旺衰都是判断吉凶的底层逻辑。

## 三、深层原理：三式贯通的"一"

在表象差异之下，三大体系共享六条根本原理：

### 3.1 象数思维

万事万物皆可转化为符号系统进行推演。三式都是"象→数→理→占"的思维链条：
- **奇门**：时间→局数→盘面符号→吉凶推断
- **紫微**：生辰→干支→星曜宫位→命理分析
- **梅花**：外应→数字→卦象→体用生克

### 3.2 触机原则

心灵与外物的感应是一切占卜的起点。
- **奇门**的"触机"在于**问事的时辰**
- **紫微**的"触机"在于**出生的时刻**
- **梅花**的"触机"在于**心动的刹那**

> 三者本质相同：在特定的时空交汇点，捕捉天地能量的信息。

### 3.3 主客辩证

"我"与"事"的关系是三式判断的核心结构：

| 体系 | "我" | "事" |
|------|------|------|
| 奇门 | 日干 | 时干 |
| 紫微 | 命宫 | 各宫位（依所问而定）|
| 梅花 | 体卦 | 用卦 |

> 共同的底层逻辑：**身要胜物则事易，物来胜身则事难。**

### 3.4 旺衰修正

同样的关系（如生、克），在不同时空条件下结果截然不同。

| 体系 | 旺衰判定方式 |
|------|--------------|
| 奇门 | 用神落宫 + 月令旺衰 = 力量系数 |
| 紫微 | 星曜庙旺利陷（在不同宫位的力量等级）|
| 梅花 | 体用卦的五行在季节中的旺相休囚死 |

> **共同公式**：吉凶结论 = 生克关系 × 旺衰系数

### 3.5 全息对应

局部反映整体，瞬间包含永恒。
- 奇门的**一个宫位**反映全局
- 紫微的**三方四正**构成自洽系统
- 梅花的一个**卦象**包含本互变错综

### 3.6 圆机应变

法无定法，因时而变。
- 奇门："一心一盘一事"，用神不固定
- 紫微："活用灵变，方为灵魂"，不拘泥于格局公式
- 梅花："要在圆机，不可执"，以理为胜不拘体用

## 四、综合运用策略

### 4.1 三式递进法

当一个问题可以从多个维度分析时：

```
① 先以梅花易数起卦
    → 快速感知事情吉凶方向（5分钟）
    → 判断此事值不值得深入分析

② 再以奇门遁甲择时择方
    → 找到最佳行动的时间窗口与空间方位
    → 选择一个"开门+生门+值符"的时辰

③ 以紫微斗数看当事人命盘
    → 从命理层次理解根本原因
    → 结合大限流年看长期运势走向
```

> **实战案例**：有人问"何时跳槽为宜"
> - 梅花 → 起卦看这件事的吉凶趋势
> - 奇门 → 选开门+生门临宫的时辰去面试
> - 紫微 → 看官禄宫大限流年，判断事业运势周期是否支持

### 4.2 体系互补表

| 场景 | 首选体系 | 辅助体系 | 说明 |
|------|----------|----------|------|
| 日常决疑 | 梅花易数 | — | 快速起卦，即时回答 |
| 择日行事 | 奇门遁甲 | 梅花易数 | 奇门择时+梅花确认 |
| 人生规划 | 紫微斗数 | 奇门遁甲 | 紫微看大势+奇门择时机 |
| 空间布局 | 奇门遁甲 | — | 九宫方位是奇门的独门优势 |
| 性格分析 | 紫微斗数 | — | 星曜宫位是最精细的性格模型 |
| 失物寻找 | 梅花易数 | 奇门遁甲 | 梅花定方向+奇门定方位宫 |
| 感情婚姻 | 紫微斗数 | 梅花易数 | 紫微看根本+梅花看当下 |
| 商业决策 | 奇门遁甲 | 紫微斗数 | 奇门选时+紫微看决策者命局 |

### 4.3 三个体系的互校互验

当两个体系给出一致结论时 → 信心大增
当两个体系给出矛盾结论时：

1. 优先以**梅花易数**为即时参考（最直接、最少干扰）
2. 以**奇门遁甲**为时空参考（最具操作性）
3. 以**紫微斗数**为根本参考（最长远、最深层的因果）

> 三式互校不是比谁"准"，而是在不同维度为同一问题提供多角度照明。

## 五、三式共同心法

### 5.1 学习心法

1. **先易后难**：梅花→奇门→紫微，由简入繁
2. **先通后专**：先掌握共同根基，再深入单一体系
3. **活学活用**：学一点用一点，在实战中巩固
4. **不贪多求快**：每个体系至少实战100例才算入门

### 5.2 断事心法

1. **一心一用**：每次专注一个问题，不贪多
2. **初念最真**：第一感觉最可靠，勿多想
3. **理象结合**：既要依理推演，也要直观感受
4. **知止不执**：占卜是参考，不是枷锁

### 5.3 境界提升

```
第一阶段：死记硬背 → 符号→对应含义（加法）
第二阶段：融会贯通 → 符号间的关系是活的（减法）
第三阶段：得心应手 → 一看便知，不需计算（心法）
第四阶段：以术证道 → 术为筏，道为岸（超越）
```

> 三式到头来，说的是同一件事：**天地人的和谐统一。**
> 奇门是"天时地利人和"、紫微是"星人合一"、梅花是"心物一元"。
