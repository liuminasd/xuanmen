道 断局精髓原则

心法第一 · 法是渡河筏，道是彼岸土

◆ 断 局 根 本 原 则 ◆
事 为 主 ， 时 为 客
所问之事决定哪个符号影响力最大。
事是断局的"锚"，一切分析围绕"事"展开，而非机械套用公式。
日干为求测人，时干为所问之事，事为主、人为辅。

奇门遁甲断局如同中医辨证——先定病位（用神），再看病性（吉凶），后断病势（应期）。一盘在手，务求心中有"事"，盘中的每一个符号都是围绕这个"事"展开的对话。

心法口诀：一心一盘一事。人与盘、盘与事本为一体。初学者愈单纯，断事愈准；学得愈杂，反而错漏增多。保持初心单纯，接近"一"便接近"道"。

第零步 · 定核心用神

断局之前的第一件事：明确"测什么"。用神选错，全盘皆错。这一步看似简单，却是整个断局的地基。用神确定之后，观察用神落哪一宫，该宫的八门、九星、八神、天干格局，就是判断的核心依据。

不同的问题，用神完全不同。同一盘面，问财和问病的结论可以截然相反——因为看的符号不同、关注的角度不同。这就是"事为主"的真义。

第一步 · 看八门 — 断近期吉凶

八门代表人事层面的短期趋势，是能量的流动出口。用神所在之宫的门，决定了事情的"门路"是否通畅。

门五行吉凶断局要点
开门金大吉事业开创、远行公开之事易成；落宫受克则开局不顺
休门水吉谈判和解、休整养生之事易成；落宫受克则进退两难
生门土大吉求财创业、生机之事易成；受克则利润微薄、难产
伤门木凶竞争博弈可用；婚嫁出行则凶；落宫得生则险中求胜
杜门木平保密藏匿可倚；公开交际则阻；技术研发之事得杜门为专精
景门火平文书考试有利；婚嫁则不宜；得吉星吉神则名利双收
死门土大凶送葬守成可用；其他诸事皆忌；落宫得吉星可减凶
惊门金凶辩论诉讼可借势；婚嫁出行则忌；口舌是非多从此来
门宫关系是判断成败的关键：门生宫 = 事情主动向有利方向发展 · 宫生门 = 环境支持事情 · 门克宫 = 事情本身有问题阻碍 · 宫克门 = 环境压制事情发展

第二步 · 看天干格局 — 断核心矛盾

天干是盘局的"戏眼"——揭示事情的核心症结所在。用神落宫的天盘天干与地盘天干的组合，以及与其他关键宫位的天干关系，构成了断局中最有信息量的部分。

天干断局中的特殊含义常见格局信号
戊资金、钱财、资本戊+庚 = 资金转移/财产变动
己欲望、私心、陷阱己+辛 = 因私欲犯错
庚阻碍、白虎、强硬力量庚+癸 = 阻力来自暗处
辛错误、罪过、瑕疵辛+壬 = 错误被放大扩散
壬流动、变化、不稳定壬+戊 = 资金流动大起大落
癸暗昧、隐情、暧昧癸+丁 = 暗中有文书麻烦
乙希望、柔韧、女性乙+庚 = 柔中带阻、事情有转机
丙权威、光明、乱子丙+庚 = 权威受阻、光明中有暗影
丁消息、文书、希望丁+癸 = 文书暗昧、消息不实
断格局心诀：天干组合如同两股力量在较量——天盘为"客"（主动方），地盘为"主"（受动方）。谁的力量强（旺衰），谁就主导格局走向。

第三步 · 看九星 — 断长期基础

九星决定事情的长期基础和天时底色。如果说八门看"一个月内"的走势，九星则看"三个月到一年"的大环境。

九星五行吉凶断局要点
天辅木吉文昌教育有利；文化辅助之象；得之则有人帮、有资源
天禽土吉中正稳定，核心位置；适合守成、巩固
天心金吉谋划智慧，适合策划、医疗；聪明人得之则事半功倍
天任土吉踏实担当，适合农业、基建；稳扎稳打之象
天冲木平冲动行动，适合武职军警；不宜久等之事
天英火平华丽文书，适合媒体公关；但易有虚火、火患
天蓬水凶冒险贪欲，需防破财受骗；水患之象
天芮土凶疾病问题，学习之象；问病则天芮为第一用神
天柱金凶破坏口舌，不适合合作；独行反而有利

第四步 · 看八神 — 断无形力量

八神代表神秘力量和无形影响，是断局中"加减分"的项目。它不决定成败的根本方向，但会大幅影响事情的顺利程度和最终体验。

八神吉凶核心影响断局信号
值符大吉首领、贵人、主导力量有贵人相助、当前环境最强能量加持
螣蛇凶虚惊怪异、纠缠、假象事情有假象、信息不实、精神焦虑
太阴吉暗中相助、密谋、庇护背后有贵人、适合暗中推进
六合吉合作、婚姻、中介撮合婚事可成、合作顺利、中间人得力
白虎凶血光、威猛、军警、压力压力巨大、意外伤害风险、但也代表执行力强
玄武凶盗贼、暗昧、暧昧、欺骗需防被骗、隐私泄露、信息不对称
九地吉(缓)稳固、迟缓、长久事成但慢、宜守不宜攻
九天吉(快)高远、主动、扬名、快速事成且快、名声远播、适合进取

第五步 · 综合串联 — 落结论

将前五步的信息串联成一条完整的逻辑链，输出清晰可执行的断局结论。这一步考验的是通盘融汇的能力，而非简单叠加。

串联示例：某人问工作变动 → 用神=开门，落离9宫 → 开门(金)克离宫(火)=门克宫，事情受阻 → 天盘庚+地盘癸=阻力来自暗处 → 天辅星=长期有贵人 → 九天=快速变化 → 结论：短期内变法困难（门克宫+庚癸暗阻），但长远有贵人相助（天辅），约3个月后（离宫数9÷3）九天主动出击可得良机。
串联维度要回答的问题信息来源
能不能成？事情的结果走向是吉是凶？八门吉凶 + 门宫生克
卡在哪里？核心阻力/症结是什么？天干格局 + 特格局
什么底色？大环境支持还是不利？九星吉凶 + 月令旺衰
有什么助力/阻力？无形力量加减分如何？八神吉凶
什么时候应？事情何时发生/何时了结？宫数 + 空亡填实 + 马星应期

一维：竖看四盘 — 一宫之内的全息解读

选定用神落宫后，垂直深入该宫的四个层次：天盘的九星（天时环境）、人盘的八门（人事状态）、神盘的八神（神秘力量）、地盘的天干（地理基础）。四层信息叠加，构成该宫完整的"能量画像"。

示例：用神落震3宫 → 天盘天辅星(文化/贵人) + 人盘开门(事业/公开) + 神盘值符(主导/权威) + 地盘坐戊(资金基础) → 四层皆吉，该宫能量非常正面，事业有贵人引路、资金基础扎实。

二维：横看生克 — 人与事的互动

日干为"我"，时干为"事"。横看生克即：日干落宫 与 时干落宫 之间的五行生克关系。这是判断"事是否利我"的核心维度。

关系含义判断要点
日干生时干我去生事 — 付出多，收获少主动投入，但事情未必回报自己 —— "身去生物"
时干生日干事来生我 — 事有利，自然而成事情对本人有益，顺势而为即可 —— "物来生身"
日干克时干我去克事 — 能掌控，但费力有能力把控，但需要付出努力 —— "身能胜物"
时干克日干事来克我 — 事情不利，难以驾驭事情超出能力范围，建议暂缓或放弃 —— "物来胜身"
日干=时干(比和)人与事同气 — 顺势自然事情与本人契合度高，顺势推进即可
心诀：身要胜物则事易，物来胜身则事难。日干与时干的生克关系，是横看生克的灵魂。

三维：时空定位 — 内外盘与应期

内盘（1-4宫）主近、主快、主本地、主内部；外盘（6-9宫）主远、主慢、主外地、主外部。用神落在内盘还是外盘，直接决定了事情的时间属性。

内盘（1·8·3·4宫）
事情来得快、离得近
应在近期（天/周）
地点以本地为主
人事关系偏内部
外盘（9·2·7·6宫）
事情来得慢、离得远
应在远期（月/年）
地点以外地为主
人事关系偏外部

四维：能量评估 — 旺衰与应期

同一个吉门，旺则吉力大，衰则吉力小；同一个凶门，旺则凶力大，衰则凶力小。月令决定五行的旺衰强弱，是衡量吉凶"力度"的标尺。

季节旺相休囚死
春（寅卯辰月）木火水金土
夏（巳午未月）火土木水金
秋（申酉戌月）金水土火木
冬（亥子丑月）水木金土火
四季末（辰未戌丑月）土金火木水
应期判断三要素：
① 宫数应期：用神落宫数 = 天数/周数/月数（如离9宫 → 9天/9周/9个月）
② 空亡填实：旬空之宫，待地支填实（如甲子旬空戌亥 → 逢戌日/亥日应）
③ 马星动应：马星所在之宫，逢冲日/合日发动

心 用神心法

日干=我 · 时干=事 · 值符=环境 · 值使=通道

用神四大定位

日干 = 求测人（"我"） 时干 = 所问之事 值符 = 大环境 / 主导力量 值使 = 事体的关键 / 执行通道

日干落宫代表求测人自身的状态、能力、位置；时干落宫代表事情本身的状态、走向、难易。值符是整盘的"天心"——大环境对事情的加持或压制；值使是"通道"——事情能否顺利执行的关卡。

用神选用的三层逻辑

层级用神回答什么问题示例
第一层：人事定位日干 + 时干"我"和"事"各自的状态如何？日干落坎1宫临休门→我目前在休整期
第二层：专项用神按问题选专项符号这件事的专项指标如何？问财看生门+戊落何宫、吉凶如何
第三层：环境通道值符 + 值使大环境和执行通道是否通畅？值符临九天→大环境有利快速行动

年命为根，月令为干，时干为梢

若求测人提供了出生年份（年命），则年命落宫代表此人的"命根子"——根本运势底色。年命宫 > 日干宫 > 时干宫，三者形成从根到梢的完整链条。年干为根（先天禀赋）、月干为干（大势所趋）、时干为梢（具体事件）。

心诀：身要胜物则事易，物来胜身则事难。日干强于时干则事在掌控之中，反之则力不从心。用神心法的本质，是找到盘中最能代表"人"和"事"的那一对符号，然后看它们之间是"相亲"还是"相斗"。

格 特格局速查表

七大格局完整解析 · 断局时必须排查的关键信号

以下七个特殊格局是断局中必须逐项排查的关键信号。任何一个特殊格局的出现，都会显著影响最终的判断结论。排查顺序：先看伏吟反吟 → 再查空亡入墓 → 后看击刑门迫 → 最后确认是否五不遇时。

格局一
伏吟
九星伏吟：天盘星与地盘星相同（星不动）
八门伏吟：人盘门与地盘门相同（门不动）
星门皆不动，整个盘面"静止"了
核心含义：事情迟缓、停滞、维持原状。天地人都"不动"，意味着事情难以推进。
何时出现：时干为甲时（天盘为甲申庚除外）容易出现伏吟。
断局要点：伏吟主"不宜动"——凡事宜守不宜攻、宜静不宜动、宜等不宜急。但并非全凶：如果问"守成、维持、稳定"之事，伏吟反而是吉兆。
应期：待冲则动——逢相冲之日（如子午冲）或相冲之月，伏吟方解。
格局二
反吟
星门对冲：天盘星或人盘门与地盘对冲
如天盘星在坎1宫、地盘星在离9宫
天地人颠倒对冲，整个盘面"动荡"了
核心含义：事情反复、变动、不稳定、折腾。事情容易出现反复、一波三折、表面上看到的和实际情况相反。
何时出现：星门落对冲之宫（坎1离9对冲、震3兑7对冲、坤2艮8对冲、巽4乾6对冲）。
断局要点：反吟主"多变"——计划易变、承诺易反悔、信息易失真。问"稳定"之事忌反吟；问"变动"之事（如跳槽、搬家）反吟反而可用。
应期：逢合则止——逢六合之日（如子丑合），反吟之气暂缓。
格局三
空亡
旬空之宫：每一旬中，天干配地支必有二支轮空
如甲子旬中戌亥为空亡
该宫能量"虚、空、假"，名存实亡
核心含义：虚空、虚假、有名无实、等待填充。用神落空亡之宫，事情处于"悬而未决"的状态。
如何查找：按时柱所在之旬确定空亡二支 → 找到对应地支所在之宫 → 该宫即为空亡宫。
断局要点：空亡之宫能量"打折"——吉事减吉、凶事减凶。用神落空亡，事情暂时"没有着落"。但也可能是"虚惊一场"（坏事落空亡 = 坏事不实）。
应期：填实则发——逢空亡地支之日/月（如空戌亥 → 逢戌日/亥日），事情方显真身。
格局四
入墓
用神天干落入其"墓"之宫
如戊入墓于乾6宫（戌为火库?不，戊为土，墓在辰/戌）
能量被"关押"了，出不来
核心含义：能量被压制、束缚、受困、不能发挥。如同人被关在房间里出不来。
五行入墓速查：甲乙木墓在未(坤2) · 丙丁火墓在戌(乾6) · 戊己土墓在辰(巽4) · 庚辛金墓在丑(艮8) · 壬癸水墓在辰(巽4)。
断局要点：用神入墓 = 能量出不来，事情难成。需待"冲墓"（对冲之支）方能解开。吉神入墓则不吉，凶神入墓则减凶。
应期：冲墓则出——如戊入墓于辰(巽4)，逢戌日(戌冲辰)则出墓。
格局五
击刑
地支相刑：用神落宫的地支与天干所带地支相刑
盘中的"法律纠纷"和"痛苦折磨"
核心含义：波折、纠纷、痛苦、刑伤。击刑是盘中最明显的"痛苦"信号——事情一定有波折、摩擦或法律层面的麻烦。
常见击刑组合：子卯刑(无礼之刑) · 寅巳申刑(无恩之刑) · 丑未戌刑(恃势之刑) · 辰午酉亥自刑。
断局要点：击刑之宫必有"痛"——问事业则有人际摩擦，问合作则有契约纠纷，问婚姻则有情感折磨。自刑（辰午酉亥）往往是自己给自己找麻烦。
化解：逢合可解——如子卯刑，逢丑(子丑合)或戌(卯戌合)可缓。
格局六
门迫
门克宫：八门五行克制其所在之宫的五行
如开门(金)落震3宫(木) → 金克木 = 门迫
事情被"门"本身堵住了
核心含义：事情受阻、门路不通、事情本身的属性与所在环境冲突，导致难以推进。
八大迫制速查：开门/惊门(金)迫震3巽4(木) · 休门(水)迫离9(火) · 生门/死门(土)迫坎1(水) · 伤门/杜门(木)迫坤2艮8(土) · 景门(火)迫兑7乾6(金)。
断局要点：门迫比门克宫更严重——门克宫是"门欺负宫"，但门迫是"门堵了自己"。吉门遇迫则吉力大减，凶门遇迫则凶上加凶。
化解：用神来制——如开门金迫震木，逢火日(火克金)可减轻门迫之力。
格局七
五不遇时
时干克日干：时柱天干克日柱天干
且为同性相克（阳克阳/阴克阴）
天时对人不利，诸事不宜
核心含义：天时与人心相悖，做什么都不顺。五不遇时是奇门中最凶的"时效格局"——一天中只有2个时辰是五不遇时，但这个时辰内诸事不宜。
如何判断：以日干查时干，看是否同性相克。
甲日 → 庚午时 / 乙日 → 辛巳时 / 丙日 → 壬辰时 / 丁日 → 癸卯时 / 戊日 → 甲寅时
己日 → 乙丑+乙亥时 / 庚日 → 丙子+丙戌时 / 辛日 → 丁酉时 / 壬日 → 戊申时 / 癸日 → 己未时
断局要点：遇到五不遇时，断局结论须"降档"——即使是吉门吉星吉神，效力也大打折扣。择日决策遇到五不遇时，直接建议换时辰。
例外：若用神得奇得门且落旺宫，可抵抗部分五不遇时的负面影响，但仍须谨慎。

七大特格局排查总览

格局本质核心三字诀吉凶转向应期关键
伏吟天地人不动守·等·静吉事缓、凶事止逢冲则动
反吟天地人对冲变·乱·反吉事变、凶事翻逢合则止
空亡能量虚空虚·空·待吉减吉、凶减凶填实则发
入墓能量被关押困·压·囚吉神不吉、凶神减凶冲墓则出

门迫门堵了自己阻·堵·卡吉门变平、凶门更凶用神化解

排查口诀：先看伏吟反吟定基调 → 再查空亡入墓看虚实 → 后看击刑门迫断困难 → 最后确认五不遇时判天时。
七格局不会同时出现，但出现任何一个都必须在断局结论中重点标注——因为它们是改变吉凶走向的"分水岭"信号。
