一、四层盘面架构

奇门遁甲的盘面由四层叠加而成，自下而上分别为地盘、人盘、天盘、神盘。每一层对应不同的时空维度，四层合参方得全貌。

👻 神盘（八神）—— 神秘力量 · 无形影响 ④
▲
⭐ 天盘（九星）—— 天时 · 能量状态 ③
▲
🚪 人盘（八门）—— 人和 · 人事吉凶 ②
▲
🗺 地盘（天干）—— 地利 · 空间基础 ①
排盘口诀：先定局布地盘 → 排星门安八神

四层盘面分别回答了四个核心维度的问题：地盘定空间（在哪里/环境如何），天盘定天时（大趋势/能量底色），人盘定人事（近期吉凶/行动方向），神盘定神助（无形力量/变数）。四层信息叠加在九宫格上，形成一个完整的时空模型。

三、定局三要素

定局是排盘的第一步，决定了整个盘面的基础。三个要素环环相扣，缺一不可。

🌓

要素一：节气定阴阳遁

冬至—夏至 → 阳遁（阳气渐长，顺排）
夏至—冬至 → 阴遁（阴气渐长，逆排）

口诀：冬至一阳生，夏至一阴生

🔢

要素二：三元定局数

符头（甲/己日）配地支定三元：
子午卯酉 → 上元
寅申巳亥 → 中元
辰戌丑未 → 下元

每元对应不同的局数（1-9局）

📐

要素三：置闰法

当节气与符头出现偏差时，通过置闰来校正。超神（符头先到）与接气（节气先到）超过九天则置闰。

置闰是奇门排盘中最精细的校正机制

📌 三元日口诀

"甲己子午卯酉为上元，甲己寅申巳亥为中元，甲己辰戌丑未为下元。"
三元定局的本质是确定每个节气15天中，当前日期落在上/中/下哪个5天区间里。以符头（日干支为甲或己的日子）为锚点，配合地支确定三元。

四、排盘6步（含空亡马星标注）

时家转盘奇门的完整排盘流程。前5步为基本排盘，第6步标空亡马星。

第一步：定局——确定阴阳遁与局数

① 看用事时间落在哪个节气区间（冬至—夏至为阳遁；夏至—冬至为阴遁）。
② 查找当日对应的符头（日干支为甲或己的日子），结合地支定三元（上/中/下元）。
③ 在节气定局表中，按三元查找局数（1-9）。
示例：冬至·上元 = 阳遁一局。

第二步：布地盘——三奇六仪飞布九宫

以局数为起点，将戊放在该宫。
阳遁顺排三奇六仪（戊己庚辛壬癸丁丙乙）→ 1→2→3→…→9→1→…
阴遁逆排三奇六仪（戊己庚辛壬癸丁丙乙）→ 9→8→7→…→1→9→…
记忆口诀："阳顺阴逆，戊起局数宫。"

第三步：定值符值使——找旬首与领袖

① 时柱的旬首（时柱属哪个六甲旬）。
② 旬首所对应的六仪落哪一宫 → 该宫的原位九星即为值符（天盘领袖）。
③ 同一宫的原位八门即为值使（人盘领袖）。
旬首速查：甲子旬→戊，甲戌旬→己，甲申旬→庚，甲午旬→辛，甲辰旬→壬，甲寅旬→癸。

第四步：转天盘——值符星飞到时干落宫

① 时干在地盘上落哪一宫？
② 值符星移动到时干所落的宫位（值符随时干而转）。
③ 其余八星按阳顺阴逆依次补满九宫。
口诀："值符随时干，阳顺阴逆转。"

第五步：转人盘——值使门按时辰推移

① 时柱在旬首之后第几个时辰？（含旬首本时）
② 值使门从原宫起，阳遁顺数（阴遁逆数）到该数字，落在对应宫位。
③ 其余七门按阳顺阴逆依次补满九宫。
口诀："值使随时支，数至时辰止。"

第六步：安神盘、标空亡马星

安神盘：八神之首值符与天盘值符同宫，其余七神按阳顺阴逆依次排布。
（顺序：值符→螣蛇→太阴→六合→白虎/勾陈→玄武/朱雀→九地→九天）

标空亡：日柱/时柱所在六甲旬的两个缺失地支所落之宫即为空亡宫。
标马星：按日支或时支定驿马方——
申子辰→马在寅；寅午戌→马在申；亥卯未→马在巳；巳酉丑→马在亥。
马星地支所在的宫位即为马星宫。

🖐 排盘6步回顾口诀

一定局 · 二地盘 · 三值符值使 · 四转天盘 · 五推人盘 · 六安神标空马
前两步定"地"，中两步转"天人"，最后一步加"神"与"变数"，六步走完，完整奇门盘即成。

五、空亡计算 + 马星定位详解

🕳 空亡（旬空）

定义：六十甲子每旬（10天）配10个地支，必有两个地支"轮空"，这两个地支所在的宫位就是空亡宫。

计算方法：

  • 看日柱（或时柱）属于哪个六甲旬
  • 该旬缺失的两个地支 → 空亡
  • 地支所在宫位 → 空亡宫

断局意义：空亡之宫能量"落空"，用神落空亡则事情虚而不实，待填实（时间推进到该地支的月/日/时）方应。

🐴 马星（驿马）

定义：马星代表变动、奔波、行动的信号。有马星的地方事情变化快，是应期的关键参考。

计算方法：以日支（或时支）查驿马所在的地支。

记忆口诀："申子辰马在寅，寅午戌马在申，亥卯未马在巳，巳酉丑马在亥。"

断局意义：马星动则事动——问出行看马星宫是否吉利，问求职马星+开门为佳，问婚姻马星可能暗示变动或异地。

💡 空亡与马星的配合使用

空亡代表"虚"和"等待"，马星代表"动"和"变化"。当马星落在空亡宫时，表示"想动却动不了"——变动之象已现，但时机未到，需待空亡填实后方可行动。反之，用神宫既非空亡又有马星，则事情进展迅速，应期就在眼前。

六、完整排盘案例

以 2024年6月15日（甲辰年五月初十）下午3点（申时） 为例，完整演示时家转盘奇门排盘。

Step 0：排四柱

年柱：2024年 = 甲辰年（年干甲，年支辰）
月柱：农历五月（午月），年干甲 → 五虎遁"甲己之年丙作首" → 正月丙寅…五月 = 庚午月
日柱：查万年历 → 戊寅日
时柱：下午3-5点=申时，日干戊 → 五鼠遁"戊癸起戊子" → 子时戊子…申时 = 庚申时

Step 1：定局

6月15日在芒种节气内（芒种约6月6日—6月20日）→ 阳遁
日柱为戊寅日 → 符头为甲戌 → 地支戌 → 下元
芒种·下元 → 查表 → 阳遁九局

Step 2：布地盘

阳遁九局：戊起离9 → 己坎1 → 庚坤2 → 辛震3 → 壬巽4 → 癸中5 → 丁乾6 → 丙兑7 → 乙艮8

Step 3：定值符值使

时柱庚申 → 查旬首：庚申属甲寅旬（甲寅→乙卯→丙辰→丁巳→戊午→己未→庚申）→ 旬首六仪为癸
地盘癸落中5宫 → 中5宫原位星天禽 = 值符，中5宫原位门（寄坤2）死门 = 值使

Step 4：转天盘

时干庚落坤2宫 → 值符天禽飞至坤2宫
其余八星阳遁顺飞补满九宫

Step 5：转人盘

庚申为甲寅旬第7个时辰 → 值使死门从坤2起顺数7位 → 2→3→4→5→6→7→8 → 落艮8宫
其余七门阳遁顺排补满九宫

Step 6：安神盘 + 标空亡马星

安神盘：值符（神）随天盘值符至坤2宫 → 阳遁顺排：值符(坤2)→螣蛇(震3)→太阴(巽4)→六合(中5)→白虎(乾6)→玄武(兑7)→九地(艮8)→九天(离9)→（接回坎1）
空亡：日柱戊寅属甲戌旬 → 空亡申酉（坤2、兑7）
马星：日支寅 → 寅午戌马在申 → 马星在坤2宫

🔑 排盘总诀 核心口诀
先定局布地盘，排星门安八神。
标空亡看马星，一盘在手万事明。

📐 定局口诀 节气三元
冬至一阳生，夏至一阴生。
阳顺阴逆分两遁，三元甲己定局神。
解读：冬至到夏至用阳遁（顺飞），夏至到冬至用阴遁（逆飞）。三元（上中下元）以甲日或己日为符头，结合地支来确定：子午卯酉为上元，寅申巳亥为中元，辰戌丑未为下元。
🗺 地盘排布诀 韵律记忆
戊起局数宫为首，六仪三奇顺逆走。
阳遁顺排九宫去，阴遁逆飞不回头。
解读：阳遁一局→戊起坎1，顺排己2庚3辛4壬5癸6丁7丙8乙9；阴遁九局→戊起离9，逆排己8庚7辛6壬5癸4丁3丙2乙1。
⭐ 天盘转动诀 值符值使
时柱旬首定值符，时干落宫星移步。
值使随支数几格，阳顺阴逆到其处。
解读：时柱的旬首对应的地盘宫原位星=值符，值符星飞到时干落宫。值使门从原宫起数到时辰的"第几格"，阳遁顺数、阴遁逆数。旬首速记：甲子①→戊、甲戌②→己、甲申③→庚、甲午④→辛、甲辰⑤→壬、甲寅⑥→癸。
👻 神盘安布诀 顺序记忆
值螣太六白玄地天，阳顺阴逆神盘安。
值符紧跟天盘走，八神依次绕宫环。
解读：八神顺序：值符→螣蛇→太阴→六合→白虎（阳遁）/勾陈（阴遁）→玄武（阳遁）/朱雀（阴遁）→九地→九天。首神值符与天盘值符同宫，其余阳遁顺排、阴遁逆排。记忆压缩："值螣太六、白(勾)玄(雀)、地天"。
🕳🐴 空亡马星诀 速算口诀
旬空两字寻地支，落入何宫能量止。
申子辰马在寅位，寅午戌马申宫驰。
亥卯未马巳方走，巳酉丑马亥上知。
解读：空亡看日柱/时柱所在旬的缺失地支，落在哪宫哪宫空。马星看日支/时支：三合局的长生位（如申子辰水局，长生在寅，故马在寅）。空亡待填实，马星主变动，二者结合看应期最准。
